# Eclipse Protocol

Jogo arcade de nave com estética em neon. Destrua os inimigos antes que eles cheguem até você!

Desenvolvido com HTML, CSS e JavaScript, o jogo funciona diretamente no navegador e oferece controles adaptados automaticamente para computadores e dispositivos mobile.

## Rodar localmente

Abra o arquivo `index.html` diretamente no navegador.

Também é possível utilizar o **Live Server** do VS Code.

## Controles

### Computador

- ← / A: mover para esquerda
- → / D: mover para direita
- ESPAÇO: atirar

### Dispositivos Mobile

Em dispositivos com tela touch, os controles são exibidos automaticamente na tela:

- ◀: mover a nave para esquerda
- ▶: mover a nave para direita
- ●: atirar

Os controles mobile são organizados de forma semelhante a um controle de videogame, com os botões de movimentação no lado esquerdo e o botão de disparo no lado direito.

## Recursos do Jogo

- Sistema de pontuação
- Sistema de vidas
- Disparo automático ao manter o botão pressionado
- Inimigos com dificuldade progressiva
- Detecção de colisões
- Efeito visual neon
- Fundo animado com estrelas
- Controles para computador
- Controles touch para dispositivos mobile
- Interface responsiva
- Adaptação automática dos controles de acordo com o dispositivo

## Como Jogar

Destrua os inimigos utilizando os controles de movimento e disparo.

A cada inimigo destruído, o jogador recebe pontos. Conforme a pontuação aumenta, os inimigos passam a aparecer com maior frequência, aumentando gradualmente a dificuldade do jogo.

O jogador começa com **3 vidas**. Uma vida é perdida quando um inimigo atinge a nave ou consegue atravessar a tela.

Quando todas as vidas são perdidas, o jogo é encerrado e a pontuação final é exibida.
